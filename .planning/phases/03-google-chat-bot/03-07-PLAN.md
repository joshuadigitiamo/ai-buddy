<objective>
Implement the thread-memory port as a small Firestore adapter plus an in-memory twin: one document per conversation keyed by an HMAC of the thread (or DM space) name, holding only the last N question/answer pairs, expiring after 24 hours.

Purpose: D-10 and D-11 allow conversation memory only with these safeguards; this plan makes them structural (the document shape cannot hold an identifier) and checks them on the emulator.
Output: `memory.py`, an offline unit test and an emulator integration test.
</objective>
