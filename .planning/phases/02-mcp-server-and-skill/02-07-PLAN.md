|----------|-------------|
| environment / secret manager -> process | secrets enter at startup |
| repository -> public internet | `.env.example`, README and Dockerfile are public |
| container image -> host | the runtime image runs on shared infrastructure later |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-29 | Elevation of privilege | container running as root | medium | mitigate | `USER 10001` in the mcp_server stage; verified by printing the uid |
| T-02-30 | Information disclosure | logs of the running process | medium | mitigate | startup log is counts, build id and mode only; process test asserts the gap question is absent from stderr |
