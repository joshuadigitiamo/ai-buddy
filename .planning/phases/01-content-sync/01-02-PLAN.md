2. schema.py: `SCHEMA_VERSION = "1.0.0"`, `SCHEMA_MAJOR = 1`, `META_KEYS = ("schema_version", "build_id", "content_hash", "guides_commit_sha", "source_doc_id", "pipeline_version", "redaction_version", "created_at_utc")`. DDL (D-08): `meta(key TEXT PRIMARY KEY, value TEXT NOT NULL)`; `handbook_pages(page_id TEXT PRIMARY KEY, parent_id TEXT, position INTEGER NOT NULL UNIQUE, depth INTEGER NOT NULL, title TEXT NOT NULL, url TEXT NOT NULL, date_edited_raw INTEGER, date_created_raw INTEGER, revision_date_iso TEXT, content_md TEXT NOT NULL, content_hash TEXT NOT NULL)`; `guide_chunks(id INTEGER PRIMARY KEY, chunk_key TEXT NOT NULL UNIQUE, file TEXT NOT NULL, h2 TEXT NOT NULL, h3 TEXT, heading TEXT NOT NULL, line_start INTEGER NOT NULL, line_end INTEGER NOT NULL, part_index INTEGER NOT NULL, text TEXT NOT NULL)`; external-content FTS5 table `guide_chunks_fts(h2, heading, text, content='guide_chunks', content_rowid='id', tokenize='porter unicode61 remove_diacritics 2')` (D-21); `video_map(chunk_key TEXT PRIMARY KEY REFERENCES guide_chunks(chunk_key), video_url TEXT NOT NULL, part INTEGER NOT NULL, start_seconds REAL, source TEXT NOT NULL CHECK (source IN ('scene', 'readme_fallback')))`. No column for ClickUp's update timestamp exists anywhere (SYNC-02: it must never influence indexing). `create_schema(conn)` executes the DDL.
3. index_writer.py: `compute_content_hash` = sha256 hex over canonical JSON (`sort_keys=True`, `separators=(",", ":")`, `ensure_ascii=False`) of schema_version, source_doc_id, guides_commit_sha, pipeline_version, redaction_version, handbook rows sorted by page_id, chunks sorted by chunk_key, videos sorted by chunk_key (D-09: logical rows, never file bytes, never build_id or timestamps). `make_build_id(now, h)` = `now` in UTC formatted `%Y%m%dT%H%M%SZ` + "-" + `h[:12]`. `build_index(content, dest, *, now)`: raise FileExistsError if dest exists; raise ValueError if a video key is not a chunk_key in content or handbook positions repeat; open sqlite3, `PRAGMA journal_mode=DELETE`, create schema, insert handbook rows by position, chunks ordered by (file, line_start, part_index) with ids 1..n, video rows, run the FTS5 `'rebuild'` command, insert meta rows (created_at_utc = ISO-8601 UTC of `now`), `PRAGMA user_version = SCHEMA_MAJOR`, commit, `VACUUM`, close; return IndexMeta. All SQL uses `?` parameters.
4. index_reader.py: `open_index(path)` opens `file:<path>?mode=ro` with `uri=True`, raises FileNotFoundError when missing, IndexVersionError when `PRAGMA user_version` differs from SCHEMA_MAJOR or when the major part of meta schema_version differs, IndexFormatError when a META_KEYS entry is missing. `to_match_query(query)`: split on whitespace, drop tokens without any alphanumeric character, double every embedded double quote, wrap each token in double quotes, join with " OR "; return None when nothing is left. `search_guides(query, limit=5)`: clamp limit to 1..50; return [] when to_match_query is None; otherwise one parameterised query joining guide_chunks_fts to guide_chunks on rowid and LEFT JOIN video_map on chunk_key, `WHERE guide_chunks_fts MATCH ?`, ranked by `bm25(guide_chunks_fts, 4.0, 6.0, 1.0)` then chunk id ascending (edge SYNC-04 ordering). `load_handbook` orders by position.
5. store.py: `ArtifactStore` Protocol and `LocalDirArtifactStore(root)`. Constructor creates root (parents, exist_ok). `latest_path` returns root/index.db when it exists, else None. `staging_path` deletes any existing `.index.*.tmp` files in root, then returns root/`.index.<uuid4 hex>.tmp` (same directory, so os.replace is atomic). `publish(staged, meta)`: compute sha256 and size of staged bytes, `os.replace(staged, root/"index.db")`, write `index.manifest.json` (keys schema_version, build_id, content_hash, created_at_utc, sha256, size_bytes) through a temp file plus os.replace, return the final path. `discard(staged)` unlinks with missing_ok.
6. tests/unit/buddy_core/test_index_roundtrip.py: build an IndexContent with two synthetic pages (parent and child; example.invalid URLs; no real ClickUp ids) and two chunks (one mapped to `VideoLink("https://videos.example.invalid/demo.mp4", 1, 312.4, "scene")`, one unmapped) into `store.staging_path()`, publish, open, then assert: load_handbook returns both pages in position order with url, title, revision_date_iso; `search_guides("chunking")` returns the mapped chunk first with its file, line_start, line_end, and `video_link(hit.video)` ending in `#t=312`; a query that only matches the unmapped chunk returns `video is None`.
