## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner -> GCP | OIDC token exchanged for a short-lived GCP token |
| third-party actions -> workflow | code from other repositories runs with the job's permissions |
| public repository -> Actions logs | logs of a public repo are readable by anyone |
